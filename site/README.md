# 衡数 Hengshu 官网（初版）

单文件静态网站：`index.html`，不依赖构建工具，双击即可在浏览器打开。

## 上线前要填的内容

- 联系方式：搜索 `待填写`，替换微信号、邮箱和小红书号
- 品牌名：「衡数 / HENGSHU」是暂定名，确定后全局替换
- 数据样例：在 `<script>` 里的 `SAMPLES` 数组中，建议请对应领域的专家逐条核对，或者换成专家出的真题（脱敏后）

## 部署

- 海外访问：GitHub Pages、Vercel、Cloudflare Pages 都可以直接托管这个文件夹
- 国内访问：服务器放在中国大陆需要先做 ICP 备案；没备案之前，可以先用香港节点托管，或者把页面链接发到微信里打开
