# Sumora 官网

- `index.html`：对外官网，极简风格，只放定位和联系方式
- `brief.html`：上一版的详细介绍页（服务、领域、数据样例），不挂链接，适合对方联系后、签完保密协议再单独发送。品牌名还是旧的「衡数」，用之前需要替换

都是单文件静态页面，不依赖构建工具，双击即可在浏览器打开。

## 上线前要填的内容

- 联系方式：搜索 `待填写`，替换邮箱和微信号
- 品牌名：「Sumora」是暂定名，商标和域名确认后再定；需要替换时全局搜索 Sumora
- 数据样例（brief.html）：在 `<script>` 里的 `SAMPLES` 数组中，建议请对应领域的专家逐条核对，或者换成专家出的真题（脱敏后）

## 部署

- 海外访问：GitHub Pages、Vercel、Cloudflare Pages 都可以直接托管这个文件夹
- 国内访问：服务器放在中国大陆需要先做 ICP 备案；没备案之前，可以先用香港节点托管，或者把页面链接发到微信里打开
